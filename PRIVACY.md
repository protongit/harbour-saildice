# Privacy Policy

SailDice does not collect, transmit or share any personal data.

- The application has no network access and requests no Sailjail permissions.
- Dice configuration and roll history are kept in memory only. They are not
  written to disk and disappear when the application is closed.
- There is no analytics, advertising, telemetry, account system or crash
  reporting.
- No device identifiers, location, contacts or files are accessed.

If you find a privacy issue, report it privately following
[SECURITY.md](SECURITY.md).
