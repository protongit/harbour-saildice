# Changelog

All notable changes to SailDice are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-10

### Added

- Native 3D renderer for real D4, D6, D8, D10, D12 and D20 polyhedra.
- Configuration for up to twelve dice with an independent type and color.
- Dice configuration page, available from the Sailfish pull-down menu.
- Animated rolls that land on the face matching each result.
- Total and per-die breakdown for every roll.
- Session history for the last 50 rolls, with confirmed clearing.
- Cover action for rolling and showing the latest result while minimized.
- English user interface.
- Sailfish OS launcher icon in all supported hicolor sizes.
- Headless self-tests for geometry, landing orientations and RNG uniformity.
