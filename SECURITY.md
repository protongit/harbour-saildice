# Security Policy

## Supported versions

Security fixes are provided for the latest SailDice release.

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
to **hensip@protonmail.com**, including:

- the affected version;
- the Sailfish OS version and device;
- reproduction steps or a proof of concept;
- the impact you believe the issue has.

You will receive an acknowledgement as soon as possible. Please allow time for a
fix and coordinated disclosure before publishing details.

SailDice performs no network requests, stores no persistent data and requests no
Sailjail permissions, which keeps the attack surface small.
